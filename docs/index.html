Razer battery monitor for macOS

Check your Razer device battery level on macOS

RazerMon is a simple menu bar app that shows the battery percentage of compatible wireless Razer mice and keyboards—without Razer Synapse.

Download for macOS View source

Free and open source · macOS 13+ · Apple silicon · 2.4 GHz USB receiver

Features

Battery status in the menu bar

See battery levels for compatible wireless Razer mice and keyboards connected through a HyperSpeed or other 2.4 GHz USB receiver. Bluetooth and cable connections are not supported.

No Synapse or device changes

RazerMon uses read-only battery queries. It does not change DPI, lighting, profiles, macros, pairing, or key bindings.

Know when it is time to charge

Check your devices in one place and avoid an unexpected low battery while working or playing.

FAQ

How do I check a Razer mouse battery level on a Mac?

Install RazerMon in Applications, launch it, and grant Input Monitoring permission. Compatible device battery levels then appear in the macOS menu bar.

Does RazerMon require Razer Synapse?

No. It communicates through macOS HID APIs and requires no Synapse installation, kernel extension, or additional driver.

Why does macOS say it could not verify RazerMon?

RazerMon is not notarized by Apple, because notarization requires a paid developer membership. macOS shows this warning for any downloaded app that has not been notarized; it does not mean a problem was found. Click Done, then open System Settings > Privacy & Security and click Open Anyway.

Why is Input Monitoring permission required?

macOS requires it before an app can open keyboard and mouse HID devices. RazerMon uses that access only to send read-only battery queries. It does not record keystrokes or pointer activity. Because the app is ad-hoc signed, macOS asks for the permission again after each update.

Does RazerMon access the network or my files?

No. The app runs in the App Sandbox with only the App Sandbox and USB device entitlements, so it has no network or file access. The README shows the codesign command to verify this.

Does it work over Bluetooth?

No. Over Bluetooth, macOS does not expose the HID report the battery query needs. Connect the device through its 2.4 GHz USB receiver instead.

Will it change my device settings?

No. RazerMon does not modify lighting, DPI, polling rate, pairing, profiles, macros, or key bindings.

What if my device is not detected?

Check the supported device list and make sure the device uses its USB receiver. If it is missing or shows as Unavailable, choose Copy Diagnostics from the RazerMon menu and paste the report into a compatibility issue together with the product name and connection mode. The report omits serial numbers.
